## ⚡ Quick Start

Follow these instructions to run the portfolio project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js 18+](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the following URL in your browser:

```text
http://localhost:5173
```

## 📝 Personalization Checklist

You can customize the portfolio with your own professional details.

| What to change | Where |
|---|---|
| GitHub profile URL | `Portfolio.jsx` → search for `https://github.com` |
| LinkedIn profile URL | `Portfolio.jsx` → search for `https://linkedin.com` |
| Resume PDF | Add your PDF to `public/` and update the resume link |
| Contact form | Replace `handleSubmit` with a Formspree or EmailJS integration |

### 📄 Add Your Resume PDF

1. Place your resume PDF inside the `public/` folder.
2. Rename it to:

```text
Jaddu_Veera_Babu_Resume.pdf
```

3. In `Portfolio.jsx`, find the Resume link and update it to:

```jsx
<a href="/Jaddu_Veera_Babu_Resume.pdf" download>
  Download Resume
</a>
```

Your resume will then be available through the portfolio website.

### 📬 Configure the Contact Form (Formspree – Free Plan Available)

To receive messages submitted through your portfolio contact form:

**1. Create an account**

Visit https://formspree.io/

**2. Create a new form**

Register your email and create a form to receive portfolio enquiries.

**3. Get your Formspree endpoint**

Example:

```text
https://formspree.io/f/YOUR_ID
```

**4. Update the `handleSubmit` function in `Portfolio.jsx`**

Example implementation:

```jsx
const handleSubmit = async (e) => {
  e.preventDefault();

  try {
    const response = await fetch(
      "https://formspree.io/f/YOUR_ID",
      {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          Accept: "application/json",
        },
        body: JSON.stringify(formData),
      }
    );

    if (!response.ok) {
      throw new Error("Message submission failed");
    }

    setFormSent(true);

    setTimeout(() => setFormSent(false), 4000);

    setFormData({
      name: "",
      email: "",
      message: "",
    });

  } catch (error) {
    console.error("Contact form error:", error);
    alert("Unable to send your message. Please try again.");
  }
};
```

Replace `YOUR_ID` with your actual Formspree form ID.

**Note:** Make sure your form field names match the properties in `formData`.
